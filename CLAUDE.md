# Project instructions for Claude Code

## Git commit / PR attribution

Do NOT add any Claude attribution to git commits or pull requests in this
repo. This overrides Claude Code's default attribution behavior entirely:

- No `Co-Authored-By: Claude ...` trailer in commit messages.
- No `🤖 Generated with Claude Code` (or any session link) in PR
  descriptions.

The user does not want their commit/PR history to show Claude involvement,
including in the closed-PR list of the upstream repo (`hardmaru/slimevolleygym`)
that PRs from their fork (`kojilbj/slimevolleygym`) may target or get
compared against.
