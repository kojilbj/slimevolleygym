#--- configuration for NEAT self-play on SlimeVolley-v0 (run 5) ---#
# Based on neat_config_selfplay.txt (run 4), with two changes made
# after finding run 4's "best" genome had no functional path from any
# of the 12 observation inputs to its outputs -- it just output a fixed
# action regardless of input (see neat/EXPERIMENT_LOG.md, run 4
# postmortem):
#   - conn_delete_prob  0.5 -> 0.2
#   - node_delete_prob  0.2 -> 0.1
# Run 4 likely lost its sensory pathways to random deletion (NEAT's
# mutate_add_node splits a connection and disables the original; if the
# new incoming half is later deleted, the new node -- and anything
# downstream of it -- becomes permanently cut off from the inputs).
# Lowering deletion rates relative to the add rates should let
# input-to-output pathways survive long enough for selection to act on
# them, instead of being pruned away before they matter.
